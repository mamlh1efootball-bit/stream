# StreamX — بازطراحی رابط کاربری (پریمیوم / سبک iOS)

## چیکار کردم
سورس کاتلین/Jetpack Compose پروژه‌ت رو بازطراحی کردم:

- **`ui/theme/Color.kt` و `Theme.kt`** — پالت رنگی جدید با گرادینت‌های آبی-بنفش-مجنتا (شبیه iOS)، سطوح شیشه‌ای (glass)، و تایپوگرافی فشرده‌تر شبیه فونت سیستمی اپل.
- **`ui/components/CommonComponents.kt`** (جدید) — کامپوننت‌های قابل استفاده مجدد: دکمه گرادینت با گلو، کارت شیشه‌ای (frosted glass)، پیل وضعیت (مثل «متصل به شبکه لایو»)، آواتار گرادینت.
- **`AuthScreen.kt`** — صفحه ورود با کارت شیشه‌ای، فیلدهای گرد، دکمه گرادینت.
- **`BroadcastSetupScreen.kt`** — دقیقاً شبیه تصویری که فرستادی: پیل سبز اتصال، دو دکمه گرادینت بزرگ (استریم صفحه‌نمایش / استریم با دوربین)، کارت خالی «هنوز استریمی روشن نشده».
- **`WatchStreamScreen.kt`** — هدر گرادینت با آواتار، لیدربورد حامیان با گرادینت طلایی، حباب‌های چت شیشه‌ای، نوار پیام شناور.
- **`MainScreen.kt`** — نوار پایین به‌صورت یک تب‌بار شیشه‌ای شناور (دقیقاً شبیه نوار پایین iOS 18)، به‌جای نوار متریال معمولی.

## ⚠️ نکته مهم: این‌جا نمی‌تونم APK بسازم
محیطی که من توش کار می‌کنم اینترنت و Android SDK نداره، پس نمی‌تونم پروژه رو کامپایل کنم و مستقیم یک فایل APK قابل نصب بهت بدم. **فقط سورس‌کد رو ویرایش کردم.**

برای گرفتن APK واقعی، دو راه داری:

### راه ۱ — ساده‌ترین: Android Studio (پیشنهادی)
۱. فایل زیپ رو دانلود کن و از حالت فشرده خارج کن.
۲. Android Studio رو باز کن → Open → پوشه پروژه رو انتخاب کن.
۳. بذار Gradle Sync انجام بشه (اولین بار به اینترنت نیاز داره تا وابستگی‌ها دانلود بشن).
۴. از منو: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
۵. فایل APK توی مسیر `app/build/outputs/apk/debug/` ساخته می‌شه.

### راه ۲ — خودکار روی GitHub (بدون نیاز به لپ‌تاپ قوی)
یک فایل Workflow برات ساختم (`.github/workflows/build-apk.yml`):
۱. یک ریپازیتوری جدید توی GitHub بساز و این پوشه رو push کن.
۲. GitHub خودش با Actions پروژه رو build می‌کنه.
۳. از تب **Actions** روی آخرین اجرا کلیک کن → پایین صفحه، فایل APK به‌صورت Artifact قابل دانلوده.

## نکته درباره دسترسی‌ها
مانیفست پروژه از قبل دسترسی دوربین، میکروفون، و سرویس فورگراند برای کپچر صفحه (media projection) رو داره — همونی که برای پخش زنده واقعی لازمه.
